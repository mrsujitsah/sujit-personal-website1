# Sujit Kumar Sah — Personal Portfolio

A responsive React + Vite personal portfolio.

## Run locally

1. Install Node.js (LTS).
2. Extract this project.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

Vite creates the production website in the `dist/` folder.

## Personalise before publishing

Update `src/App.jsx`:
- Replace `YOUR_EMAIL@example.com` with your public contact email.
- Replace LinkedIn and GitHub links with your profile URLs.
- Confirm the current-role wording and dates.
- Add any projects you want to showcase.
- Add a profile photo if you want one.

The current-role company is intentionally left generic pending confirmation.
